# wachtel.us

The apex page for `wachtel.us`, served by GitHub Pages. It serves the Commonplace icon (so Google's favicon service, and through it claude.ai's connector list, shows it for `*.wachtel.us`) and sends visitors on to https://commonplacememory.com.

DNS for `wachtel.us` is at Network Solutions: four apex A records to GitHub Pages (185.199.108.153, .109.153, .110.153, .111.153) and `www` CNAME `sammywachtel.github.io.`. Mail (MX, SPF, DKIM, DMARC) and the `gcp.wachtel.us` delegation are separate records and are not part of this site.

Icons are copies of `src/commonplace/browser/assets/` in DAS-Kollektiv/commonplace.
